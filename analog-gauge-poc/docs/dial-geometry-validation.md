# 表盘圆形与椭圆几何验收

本文规定圆形表盘在斜拍照片中形成椭圆时的通用验收方法。它适用于完整圆形外壳或圆环；真实椭圆表盘、半圆表、四分之一圆表和没有足够可见圆弧的仪表应走各自的几何路径。

## 候选与选择

先生成多个椭圆候选，再验证候选。尺寸只用于在已经可靠的候选中区分外圈和内圈，不能单独证明候选正确。

每个候选至少记录并检查：

- 可见椭圆周长与实际图像边缘的贴合率；
- 椭圆周长落在图片范围内的可见比例；
- 长短轴比例、中心位置和拟合残差是否合理；
- 是否存在可由同一相机姿态校正为同心圆的内外物理圆环、刻度或表盘内容；
- 候选用于姿态校正后，刻度半径和指针几何是否比校正前更一致。

当前完整圆环的强边缘路径要求可见圆弧边缘贴合率不低于 `80%`，且至少 `50%` 的拟合周长位于图片范围内。阈值按比例定义，不绑定固定分辨率。贴合率只说明椭圆附近存在边缘，不能证明这些边缘属于同一个物理圆环；必须验证至少两条不同半径的物理环能否由同一个姿态变换校正为同心圆。透视投影下，物理圆心的像不一定等于椭圆几何中心，不能在原图中强迫二者重合；应使用可见指针轴心与椭圆的极线关系恢复表盘平面的消失线，再检查校正后的同心性。尺寸只能在姿态一致的候选组内用于区分内外圈。

照片裁掉少量外圈时，只对落在图片范围内的圆弧计算贴合率。压缩、遮挡或断裂会令像素级覆盖低于 `80%`，此时只有长轮廓的姿态和几何误差通过门槛，才能作为独立证据。边缘搜索必须按角度扇区检查分布，允许少量遮挡，但不能让一段强阴影代替完整上半圈；一个候选只有在另一条不同半径的实体环也支持同一透视姿态时才能升级为双环路径。不得把法兰、螺钉、阴影和设备外壳的碎片拼成单个高分椭圆。既没有强边缘候选，也没有可靠轮廓姿态时，椭圆路径必须返回未识别。

透视校正属于高自由度路径，目前只在有效表盘短边至少 `800 px` 且可见轴心圆能复核分割中心时启用。低于该信息量时保留原有仿射或未识别结果，避免低清纹理制造伪双环。阈值是当前真实批次回归得到的保守边界；未来调整必须新增清晰度分层实验，不能只改一个常量。

## 下游交叉验证

将选中椭圆校正为圆形后继续检查：

- 刻度是否围绕合理中心分布，半径离散度是否合理；
- 指针或其延长线是否与轴心几何一致；
- 有效刻度弧、指针方向和量程端点是否一致；
- 多个证据分支有分歧时，保留多个候选并比较整体几何，不让单个错误分支否决或决定全部结果。

几何检查失败时应明确记录失败边界，不得依靠量程端点吸附、离散值归整或人工答案掩盖错误轴心和错误椭圆。

## 回归与审计

椭圆相关改动同时验证中间几何和最终读数：

1. 单元测试包含完整外圈、同心内外圈、比真实外圈更大的局部弱弧、遮挡和裁剪场景；
2. 真实图片报告保留候选框、最终椭圆、姿态校正、轴心、指针和刻度映射图；
3. JSON 阶段说明记录外圈边缘贴合率、独立内圈支持率、校正后半径比例和采用的仿射/透视路径；
4. 对历史批次逐通道比较状态、值和候选，并逐张审阅发生几何变化的中间图。

最终读数一致不等于几何回归通过。只有质量指标、中间图和最终结果均符合预期，才能报告当前验证未发现回归。

## 姿态读取契约

完整圆形仪表不能把椭圆拟合只当作展示框。可靠外圈用于建立相机姿态基准；外圈、内圈、轴心与指针端点必须使用同一个校正变换进入正视坐标，再在该坐标中计算角度。弱透视可使用仿射变换；斜拍明显且双环、可见轴心证据充分时使用透视变换。透视圆形校正仍存在一个平面内旋转自由度，必须以原仿射坐标的零方向锚定，不能让校正额外旋转刻度角。报告至少展示原裁剪上的内外圈拟合、可见轴心、校正后表盘和校正后指针，并记录边缘贴合率、可见圆弧比例、内圈支持率和半径比例。

类型专用分支也必须遵守这一契约。离散表盘可以在校正角度上归整到允许值，但归整不能掩盖错误外圈；连续表盘必须在校正后完成角度及刻度映射。外圈不可靠时，只能使用明确标记、且具有独立几何证据的降级路径。

## 阶段性基线（2026-09-04）

当前 `448-highres-pad` 批次在已保留的现场图片上，表盘定位、指针方向和主要读数整体已达到较满意的阶段性结果，可作为后续优化的回归基线。这不表示所有圆形仪表都已通过姿态几何验收。

KEOI 原图曾先后出现两个伪成功：一版得到 `84.6%` 和 `82.3%` 的高贴合率，却把法兰、阴影和螺钉附近边缘拼成不存在的“大椭圆”；另一版把单圈局部贴边误当成姿态正确，上半圈仍被阴影吸走。当前路径改为“长轮廓给搜索先验、可见金属轴心排除暗影圆、不同半径内外环共同验证透视姿态、仿射零方向消除旋转歧义”。两条独立读取路径的内圈支持率分别为 `68.0%` 和 `65.3%`，校正后内外圈半径比例均为 `0.805`；连续读数为 `3.444`，符合人工观感约 `3.4`。JS-9 类型专用路径保持原结果 `0`。

对 `iter1`、`iter2`、`iter2-原图` 和 `iter3` 的逐通道、逐中间图回归中，除 KEOI 原图的两组椭圆、校正、掩膜、指针和刻度阶段及读数由 `3.384` 调整为 `3.444` 外，其余通道状态、值和可比中间图逐字节保持旧基线。第一次全量回归曾发现低清 `iter1` 被透视路径误触发；增加 `800 px` 信息量门槛后，极模糊图片恢复为 `not_recognized`，没有用高自由度几何制造数值。

当前仍不能把这一批次结论推广到任意新仪表：真实椭圆表盘、半圆和四分之一圆表不适用完整圆外圈契约；严重透视、外圈不可见或多个物理圆环无法区分时仍需新样本和独立几何证据。不得通过写入固定读数、固定轴心或单图坐标规避。

## 知识边界

本文件保存跨仪表类型的几何验收规则。某类仪表特有的结构事实，例如 JCQ 避雷器监测器的调零螺钉不是隐藏指针轴心，只写入对应仪表类型的 `metadata.json`，不复制到其他类型。
