# 表盘圆形与椭圆几何验收

本文规定圆形表盘在斜拍照片中形成椭圆时的通用验收方法。它适用于完整圆形外壳或圆环；真实椭圆表盘、半圆表、四分之一圆表和没有足够可见圆弧的仪表应走各自的几何路径。

## 候选与选择

先生成多个椭圆候选，再验证候选。尺寸只用于在已经可靠的候选中区分外圈和内圈，不能单独证明候选正确。

每个候选至少记录并检查：

- 可见椭圆周长与实际图像边缘的贴合率；
- 椭圆周长落在图片范围内的可见比例；
- 长短轴比例、中心位置和拟合残差是否合理；
- 是否存在支持同一中心和姿态的同心圆环、刻度或表盘内容；
- 候选用于姿态校正后，刻度半径和指针几何是否比校正前更一致。

当前完整圆环路径要求可见圆弧边缘贴合率不低于 `80%`，且至少 `50%` 的拟合周长位于图片范围内。阈值按比例定义，不绑定固定分辨率。通过质量门槛后，再选择直径最大的可靠候选作为外圈姿态基准。

照片裁掉少量外圈时，只对落在图片范围内的圆弧计算贴合率。可见范围不足或所有候选均未通过门槛时，专用椭圆路径必须返回未识别，由其他可验证路径继续处理；不能退回到“选择最大候选”。

## 下游交叉验证

将选中椭圆校正为圆形后继续检查：

- 刻度是否围绕合理中心分布，半径离散度是否合理；
- 指针或其延长线是否与轴心几何一致；
- 有效刻度弧、指针方向和量程端点是否一致；
- 多个证据分支有分歧时，保留多个候选并比较整体几何，不让单个错误分支否决或决定全部结果。

几何检查失败时应明确记录失败边界，不得依靠量程端点吸附、离散值归整或人工答案掩盖错误轴心和错误椭圆。

## 回归与审计

椭圆相关改动同时验证中间几何和最终读数：

1. 单元测试包含完整外圈、同心内外圈、比真实外圈更大的局部弱弧、遮挡和裁剪场景；
2. 真实图片报告保留候选框、最终椭圆、姿态校正、轴心、指针和刻度映射图；
3. JSON 阶段说明记录椭圆边缘贴合率；
4. 对历史批次逐通道比较状态、值和候选，并逐张审阅发生几何变化的中间图。

最终读数一致不等于几何回归通过。只有质量指标、中间图和最终结果均符合预期，才能报告当前验证未发现回归。

## 阶段性基线（2026-09-03）

当前 `448-highres-pad` 批次在已保留的现场图片上，表盘定位、指针方向和主要读数整体已达到较满意的阶段性结果，可作为后续优化的回归基线。这不表示所有圆形仪表都已通过姿态几何验收。

已知限制：

- KEOI 油位指示器在一张原图的 `full-image-fallback` 路径中，通用椭圆候选只有约 `42%` 的可见圆弧边缘贴合率，低于本文定义的 `80%` 门槛，却仍被旧通用路径接受。当前读数接近人工观感，但该椭圆不得作为已通过的姿态校正证据。后续需将边缘贴合率和可见圆弧门槛统一到通用椭圆路径。
- JS-9 放电计数器当前使用彩色指针连通域与霍夫直线直接读取 `0–9` 离散位置，没有执行外圈椭圆检测和斜拍姿态校正，因此阶段报告中也没有椭圆拟合图。当前近似正拍样本可用；明显斜拍、反光或阴影场景尚未获得外圈姿态证据，不应推广为该类型已全面解决。

上述两项属于后续通用几何改进，不得通过写入固定读数、固定轴心或单图坐标规避。

## 知识边界

本文件保存跨仪表类型的几何验收规则。某类仪表特有的结构事实，例如 JCQ 避雷器监测器的调零螺钉不是隐藏指针轴心，只写入对应仪表类型的 `metadata.json`，不复制到其他类型。
