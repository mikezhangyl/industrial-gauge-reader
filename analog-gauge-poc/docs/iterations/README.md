# Gauge Reader 迭代协议

从 `Iteration 001` 开始，每轮只处理一组可证伪的假设，编号顺序递增：

```text
Observe：记录原始输入、当前输出、耗时和失败阶段
Hypothesize：提出 3–5 个有明确预测的假设并排序
Act：只修改验证本轮假设所需的最小实现
Verify：运行新样本、历史回归、测试、规范检查和 benchmark
Reflect：记录哪些假设成立、哪些被否定、遗留风险和下一轮入口
```

每轮文件命名为 `iteration-NNN.md`，必须包含：

- 输入文件及 SHA-256；
- 不可违反的约束；
- 基线命令和原始输出；
- 假设、预测、行动与验收标准；
- 实际结果及证据文件；
- 下一轮建议。

不得为了通过单张图片而在生产代码中写死 ROI、中心、角度、刻度或读数。测试可以保存人工核验的期望结果，但必须与生产实现隔离。
