# Camera PoC Iteration 009：识别与隐私处理完全分开

状态：`IMPLEMENTED_AWAITING_LIVE_RUN`

## 决定

本 PoC 以识别和失败诊断为优先。隐私虚化不能改变模型输入，也不能销毁漏检证据。

## 新顺序

```text
清晰摄像头原图
→ 闹钟检测和读数
→ 如果检测成功：保留闹钟清晰，虚化背景
→ 如果检测失败：不虚化，保存清晰原图供复盘
```

JSONL 和 HTML 报告按帧记录是否真的进行了背景虚化，不再用一个会话开关代表所有帧。

## 代价

漏检帧会保存人物和房间的清晰画面。这是为了保留真实失败证据而做的明确取舍，报告中会显示哪些帧没有虚化。
