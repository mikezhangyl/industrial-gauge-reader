# Camera PoC Iteration 006：背景隐私保护

> 后续修正：Iteration 009 改为诊断优先。只在检测成功后虚化背景；漏检帧保留清晰原图，下面“未检测时整帧虚化”仅是当时的历史方案。

状态：`IMPLEMENTED_OFFLINE_VISUAL_CHECKED_AWAITING_LIVE_CAMERA_CHECK`

## 目标

摄像头仍需使用完整清晰画面寻找闹钟，但人物、房间和私人用品不应清晰显示或保存。

## 实现

1. 原始摄像头画面只在内存中用于闹钟和秒针识别。
2. 识别到闹钟后，只保留闹钟周围的椭圆区域清晰，其他区域强力虚化。
3. 尚未找到闹钟时整张画面虚化，避免程序刚启动时暴露人物和房间。
4. 虚化边缘使用柔和过渡，不产生生硬的矩形切口。
5. 实时窗口、事件截图、逐帧归档和HTML报告全部使用隐私处理后的画面。
6. JSONL记录是否开启隐私处理，HTML报告也明确显示隐私状态。

## 验证

- 自动测试确认仪表中心像素保持清晰，背景细节显著降低。
- 自动测试确认没有检测到闹钟时整张画面都会虚化。
- 使用上一轮真实摄像头画面完成离线视觉检查：闹钟表盘保持清晰，人物、手臂和房间背景明显虚化。
- 1280×720画面的隐私处理实测约增加20毫秒，并计入报告处理耗时。
- 旧session不会自动处理；此前保存的清晰背景仍在旧目录中，如需删除应单独确认范围。
