# 摄像头闹钟 PoC：当前阶段与下一步

更新日期：2026-08-21

## 一、现阶段结论

本项目已经完成从 MacBook 摄像头画面中自动寻找闹钟、校正表盘、跟踪秒针、换算秒数、判断报警区间、保存实验截图和生成中文报告的完整 PoC 链路。

目前可以得出以下结论：

1. 红色京宝石英钟的现场回测效果很好，说明当前方案在表盘清楚、秒针与背景对比明显的情况下已经具备稳定演示能力。
2. 银色钟明显更难。银色放射纹表盘、金属反光、多根颜色接近的指针，会削弱细秒针与背景之间的区别。
3. 当前程序不会为了保持“始终有读数”而接受不可信结果。通道交接不连续时会显示未知，避免认错指针和错误报警。
4. 本阶段目标是验证技术路线，而不是证明已经达到生产环境的准确率和可靠性。

## 二、当前已经做到的能力

### 1. 自动寻找闹钟

- 输入是摄像头完整画面，不需要人工指定固定区域。
- 使用预训练 YOLO 模型寻找 `clock`。
- 对模型误标为 `frisbee` 的候选，使用钟面数字进行二次确认。
- 闹钟移动、缩放或短时漏检时，可以进行一定程度的连续跟踪。

### 2. 表盘几何校正

- 自动估计表盘外圈和指针轴心。
- 对侧拍造成的椭圆和透视变形进行校正。
- 利用刻度和 OCR 识别的钟面数字恢复真实的十二点方向。

### 3. 秒针识别与跟踪

- 使用连续帧判断哪根指针按照秒针规律运动。
- 普通灰度和局部对比度增强两路分别跟踪，根据真实运动证据选择更合适的图像通道。
- 主通道暂时失效时，备用通道可以接手。
- 通道交接必须符合上一读数推算的位置，避免秒数突然跳变。
- 单帧模糊时允许短时间预测保持，并明确标记为预测结果。

### 4. 演示和审计能力

- 实时显示秒数、识别状态和报警状态。
- 支持 `50～59` 秒报警区间演示。
- 保存逐帧记录、截图和 JSONL。
- 自动生成全中文 HTML 实验报告。
- 只有成功检测到闹钟后才虚化背景；隐私处理不参与识别判断。

## 四、当前主要限制

### 1. 银色反光表盘

银色钟是当前最明显的难点：

- 表盘纹理会产生大量从中心向外延伸的亮暗线。
- 反光会随着摄像头和闹钟位置变化，看起来像一根移动的指针。
- 秒针、时针、分针颜色接近，指针重合时信息可能暂时消失。
- 失焦或运动模糊发生后，软件无法恢复原图中已经丢失的细节。

### 2. 首次确认和重新确认需要时间

程序必须观察连续运动，才能确认哪根是秒针。因此闹钟刚进入画面、位置发生较大变化或轨迹丢失后，会暂时显示未知。这是防止认错指针的安全设计。

### 3. 还没有正式的人工真值数据

目前主要依据连续运动是否合理来评价稳定性。要证明绝对读数准确，需要保存摄像头帧，并对每个关键帧人工标注真实秒数、表盘是否完整、是否反光和是否失焦。

### 4. 还不是生产监控系统

当前没有覆盖摄像头断线恢复、长时间无人值守、设备健康检查、报警通知、人工确认、重复报警抑制和运行监控等生产能力。

## 五、建议的下一步

### 优先级一：固定当前红色钟演示基线

如果近期需要演示，优先使用红色京宝石英钟和当前代码，不继续为银色钟修改核心逻辑。

建议保存一次稳定的两分钟现场 session，作为以后所有修改必须通过的回归基线。需要记录：

- 首次取得秒针读数的时间。
- 锁定后的连续读数率。
- 错误跳变次数。
- 进入和离开报警区间是否正确。
- 完整链路 p50 和 p95 耗时。

### 优先级二：建立少量人工真值

从红色钟和银色钟各选择一小段代表性录像，对关键帧标注真实秒数以及反光、模糊、遮挡和移动状态。以后优化不能只看“读数更多”，还要同时检查是否读对。

### 优先级三：如果必须继续攻克银色钟

可以按以下顺序继续实验：

1. 锁定摄像头曝光和对焦，先减少输入画面自身波动。
2. 在表盘校正后增加反光区域检测，对强反光区域降低权重。
3. 使用更长的时间窗口追踪整条指针轨迹，而不是只比较相邻两帧。
4. 利用指针必须从轴心连续延伸到外圈的形状约束，进一步排除放射纹理。
5. 评估偏振片、调整光源和摄像头角度等物理方案。对于金属反光，改善采集条件通常比继续堆软件滤镜更有效。

### 优先级四：回到工业仪表场景

闹钟实验中值得带回工业项目的经验包括：

- 完整画面自动检测仪表。
- 表盘透视校正。
- 多种图像处理通道的现场选择。
- 指针必须从中心延伸到刻度环的约束。
- 不确定时输出未知，而不是伪造数值。
- 用连续帧和报告保存现场证据。

不能直接复用的闹钟专属规则包括：

- 秒针约每秒转动六度。
- 一圈等于六十秒。
- `50～59` 秒报警区间。
- COCO 的 `clock/frisbee` 类别和钟面 `1～12` 数字映射。

工业仪表下一阶段仍需重新解决量程、刻度值、单位和报警阈值解释。

## 七、阶段性决定

当前版本可以作为 MacBook 摄像头闹钟 PoC 的阶段性成果封存。红色京宝石英钟用于稳定演示；银色钟保留为高难度回归样本。除非后续业务场景明确要求处理类似银色强反光表盘，否则不建议继续围绕该单一闹钟过度优化。
